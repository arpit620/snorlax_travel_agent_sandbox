# Travel Agent RAG

An experimental AI travel assistant that answers travel questions using company travel policies, destination information, and employee preferences. It combines retrieval-augmented generation with policy checks, local search, and optional enterprise integrations.

## What it does

- Retrieves relevant company and destination guidance from a SQLite knowledge index.
- Checks policy applicability and presents evidence with answers.
- Supports itinerary planning, local search, and optional enterprise actions.
- Includes scripts for building and maintaining the knowledge index.
